## 修复：惠惠不显示 + 三个新模型过小（同一根因的两个表现）
- 根因1：cubism3.js 里 swapCanvas(true) 在画布创建前调用 → 首次进 Cubism3 模型时 #live2d-cubism 一直 display:none。惠惠是循环里第一个 Cubism3 模型，所以只有它"没加载出来"。修正：先 mountModel（内部创建画布）再 swapCanvas(true)。
- 根因2：缩放按 model.width/height（3000x4500 画布信息）算，内容只占中间且中心偏移 → 又小又偏。改为遍历 coreModel.getDrawableVertices 求内容包围盒；顶点空间 y 向上、渲染时绕画布中心翻转，中心换算 = (canvasW/2 + cx, canvasH/2 - cy)。FILL=1.0 时内容撑满画布。
- 实测（Chromium + agent-browser，像素级 bbox）：加藤惠 112x245 / 惠惠 118x239 / 达克妮丝 117x248 / 阿克娅 136x249，切回旧模型重载后仍是 112x245。
- 环境经验：agent-browser 守护进程不跨 Bash 调用存活，一次命令里要串完 open→wait→eval→screenshot；沙箱有 http_proxy 会拦截 localhost，需用 env -u http_proxy... 启动；localhost 静态服务用 python -m http.server + curl --noproxy。
